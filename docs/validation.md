# اعتبارسنجی و کنترل کیفیت

## تست خودکار
```bash
python -m compileall -q src tests scripts
python -m unittest discover -s tests -v
```

## اصول
- داده OHLC باید مرتب، بدون timestamp تکراری و دارای OHLC سازگار باشد.
- فقط کندل‌های بسته‌شده وارد محاسبات می‌شوند.
- ۴H فقط از ۱H کامل ساخته می‌شود و هر بازه باید چهار کندل ساعتی داشته باشد.
- داده ناقص/قدیمی باعث unrankable یا watchlist می‌شود.
- هزینه نامشخص null است و R/R خالص محاسبه نمی‌شود.
- تعداد فرصت‌های فعال می‌تواند صفر تا ده باشد.
- آزمون‌های بک‌تست و Paper Trading باید شامل هزینه، لغزش، شکاف و جلوگیری از look-ahead باشند؛ تا ایجاد آرشیو تاریخی معتبر، عملکرد آینده‌نگر ادعا نمی‌شود.
