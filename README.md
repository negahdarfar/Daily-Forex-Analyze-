# Daily Market Analyze

سامانه مستقل تحلیل روزانه بازارهای مالی؛ با سه موتور:

1. **Live Intelligence** — گردآوری داده‌های قیمت و زمان دریافت آن‌ها.
2. **Expert Intelligence** — ثبت و ارزیابی تحلیلگران و تریدرها بر پایه شواهد قابل بررسی.
3. **Independent Intelligence** — تحلیل تکنیکال مستقل، سناریوهای جایگزین و رتبه‌بندی فرصت‌ها.

> این نسخه، اسکلت اجرایی اولیه (MVP) است. هیچ عملکرد معاملاتی، نرخ برد یا داده زنده‌ای را جعل نمی‌کند. هر منبع باید زمان داده، محدودیت و وضعیت اعتبار خود را اعلام کند.

## پوشش دارایی‌ها

- ۲۸ جفت‌ارز اصلی و کراس فارکس
- طلا، نقره و نفت
- بیت‌کوین و اتریوم
- دلار/ریال، طلای ایران و تتر ایران: فقط با منبع محلی قابل‌ردیابی و timestamp؛ تا زمان پیکربندی منبع معتبر، با وضعیت «داده در دسترس نیست» نمایش داده می‌شوند.

## اجرای خودکار

GitHub Actions هر روز ساعت **۰۷:۰۰ تهران (۰۳:۳۰ UTC)** اجرا می‌شود و گزارش را در `reports/YYYY-MM-DD.md` ثبت می‌کند. اجرای دستی نیز از تب Actions امکان‌پذیر است.

## اجرای محلی

```bash
python -m pip install -r requirements.txt
python -m src.main
```

## ساختار

- `config/assets.json`: فهرست دارایی‌ها و نمادهای داده
- `config/settings.json`: تنظیمات اجرا و محدودیت‌ها
- `src/data/`: دریافت داده، کنترل تازگی و گردآوری RSS عمومی با timestamp
- `src/technical/`: شاخص‌ها و سناریوهای تکنیکال
- `src/experts/`: رجیستری تحلیلگران، محاسبه عملکرد معاملات تأییدشده و استخراج سرنخ‌های تحلیل از تیتر/خلاصه RSS
- `src/reporting/`: تولید گزارش فارسی
- `data/analysts.json`: پروفایل‌های کارشناسی؛ در شروع خالی و بدون ادعای تأیید
- `data/forecasts.csv`: دفتر ثبت پیش‌بینی‌ها برای ارزیابی آینده‌نگر
- `data/trader_trades.csv`: دفتر معاملات بسته برای محاسبه expectancy، profit factor و drawdown؛ معاملات تأییدنشده وارد رتبه‌بندی نمی‌شوند
- `reports/`: گزارش‌های روزانه

## منابع چندگانه قیمت

- فارکس، طلا، نقره و نفت در این نسخه همچنان از Yahoo Finance دریافت می‌شوند؛ این دارایی‌ها هنوز منبع جایگزین مستقل ندارند.
- برای BTC و ETH، Yahoo Finance و API عمومی Binance بررسی می‌شوند و تاریخ آخرین کندل تکمیل‌شده مبنای انتخاب منبع است.
- کندل روزانه باز Binance حذف می‌شود تا قیمت موقت کندل جاری به‌عنوان قیمت بسته‌شدن قطعی استفاده نشود.
- اگر هر دو منبع رمزارز در دسترس باشند، منبع دارای timestamp جدیدتر انتخاب می‌شود؛ اگر یکی خطا بدهد، منبع معتبر دیگر می‌تواند استفاده شود.
- این اتصال Binance فقط داده عمومی بازار اسپات را می‌خواند و به کلید API یا دسترسی حساب کاربری نیاز ندارد.

## اصول داده و اعتبارسنجی

- زمان انتشار، زمان جمع‌آوری و زمان بازار از هم جدا هستند.
- قیمت Yahoo Finance در این پروژه صرفاً منبع رایگان اولیه و ممکن است تأخیردار، ناقص یا غیرقابل‌دسترس باشد؛ برچسب «لحظه‌ای» فقط با مدرک منبع مجاز است.
- اخبار در نسخه فعلی فقط از RSSهای عمومی پیکربندی‌شده دریافت می‌شوند؛ شبکه‌های اجتماعی و کانال‌های خصوصی بدون API یا دسترسی مجاز scrape نمی‌شوند.
- برچسب نوع منبع خبری، رتبه‌بندی اعتبار مستقل نیست؛ اعتبارسنجی جداگانه و تحلیل معنایی خبرها هنوز در حال توسعه است.
- داده‌ای که از آستانه تازگی عبور کند از رتبه‌بندی فرصت‌ها کنار گذاشته می‌شود.
- تعداد دنبال‌کننده، ادعای win rate و تبلیغات، مدرک عملکرد نیستند.
- ارزیابی عملکرد به تعداد نمونه، expectancy، profit factor، drawdown، R:R و قابلیت راستی‌آزمایی نیاز دارد.
- نرخ‌های ایران تا زمان اتصال چند منبع محلی معتبر، حدس زده یا جایگزین نمی‌شوند.
- گزارش آموزشی/اطلاعاتی است و توصیه قطعی خریدوفروش نیست.

## Secrets

نسخه پایه برای دریافت داده‌های عمومی به API key نیاز ندارد. هر کلید احتمالی در آینده فقط باید در **Settings → Secrets and variables → Actions** ذخیره شود؛ هرگز در کد، گزارش یا commit قرار نگیرد.

## وضعیت توسعه

این نسخه زیرساخت اولیه را ایجاد می‌کند. تحلیل معنایی اخبار و دیدگاه‌های مخالف/موافق، اتصال مجاز منابع اجتماعی، اعتبارسنجی مستقل سوابق تریدرها، داده‌های محلی ایران، نمودارهای پیشرفته و بک‌تست پیش‌بینی‌ها در مراحل بعدی افزوده می‌شوند.

## رجیستری ۱۰۰ منبع پژوهشی

رجیستری `config/analysis_sources.json` دقیقاً ۱۰۰ منبع پیشنهادی کاربر را به ترتیب شش گروه نگه می‌دارد: منابع رسمی/اولیه (۳۵)، تقویم و ابزار داده (۱۵)، خبرگزاری‌ها (۲۰)، انرژی (۱۰)، فلزات (۸) و تحلیل فارکس (۱۲). برای هر منبع authority score اولیه، نوع منبع، روش دسترسی، وضعیت اتصال و یادداشت سوگیری ثبت شده است. این امتیاز، سابقه دقت پیش‌بینی نیست.

- فقط منبعی که روش دسترسی‌اش مستند و مجاز باشد می‌تواند فعال شود.
- هشت منبع رجیستری فعال‌اند: پنج RSS عمومی/رسمی (BBC Business، CNBC Markets، FXStreet، Federal Reserve Monetary Policy و BLS Latest Releases) و چهار API رسمی بدون کلید (ECB، World Bank، BLS v1 و CFTC Public Reporting). BLS هم‌زمان API و RSS دارد. BLS با یک درخواست روزانه کم‌تعداد دریافت می‌شود؛ CFTC فقط یک درخواست تجمیعی دارد و نباید بیش‌ازحد فراخوانی شود. محدودیت استفاده غیرتجاری FXStreet رعایت می‌شود؛ لینک و فراداده/خلاصه کوتاه نگهداری می‌شود، نه متن کامل مقاله. ۹۲ منبع دیگر فقط در رجیستری ثبت شده‌اند و تا اعتبارسنجی feed/API و مجوز استفاده، اتصال خودکار ندارند.
- Forex Factory، TradingView و شبکه‌های اجتماعی در حالت API رسمی/بررسی دستی هستند؛ scraping خودکار بدون مجوز انجام نمی‌شود.
- امتیاز authority یک prior برای وزن‌دهی است؛ منبع رسمی برای داده رسمی معتبرتر است، اما تحلیل بروکر یا رسانه همچنان باید با داده اولیه و شواهد مستقل تأیید شود. خبرهای تکراری از یک سیم خبری چند تأیید مستقل محسوب نمی‌شوند.
- گزارش روزانه تعداد منابع ثبت‌شده، فعال، نیازمند مجوز و دستی را نمایش می‌دهد.

**مهم:** رجیستری ۱۰۰ منبع با ترتیب و وزن اولیه اعتبار ساخته شده، در مجموع ۸ منبع رجیستری فعال‌اند (۵ RSS و ۴ API؛ BLS در هر دو دسته است)؛ ۹۲ منبع هنوز نیازمند ارزیابی و اتصال مجازند. جدول ده جفت‌ارز در گزارش فعلاً رتبه‌بندی تکنیکال موقت بر اساس EMA/RSI و تازگی داده است؛ تحلیل بنیادی و تقویمی هنوز به آن متصل نشده و نباید به‌عنوان سیگنال کامل ورود تلقی شود.

## ارتقای موتور تحلیل و اتصال رسمی منابع

- موتور تکنیکال چندعاملی از EMA alignment/slope، RSI، MACD histogram، ADX/+DI/-DI، شکست ساختار ۲۰ کندلی و تأیید حجم در صورت وجود استفاده می‌کند. امتیاز، قدرت قاعده‌محور است و احتمال موفقیت نیست.
- حد ضرر با ترکیب ATR و swing اخیر تعیین می‌شود؛ هدف ابتدا با ساختار اخیر سنجیده می‌شود و فقط در نبود هدف ساختاری مناسب از ضریب R تنظیم‌شده استفاده می‌کند. R:R از سطوح محاسبه می‌شود و نباید بدون بک‌تست، نتیجه عملکرد تلقی شود.
- رجیستری ۱۰۰ منبع، مرجع فعال‌سازی RSS است؛ وجود URL در فایل پیکربندی به‌تنهایی مجوز اجرا نمی‌دهد.
- CFTC برای هر قرارداد تا ۵۲ هفته داده هفتگی دریافت می‌کند و صدک موقعیت‌گیری، Z-score و تغییر چهار هفته‌ای را محاسبه می‌کند؛ اگر حداقل ۲۶ مشاهده موجود نباشد، آمار ۵۲هفته‌ای نمایش داده نمی‌شود.
- چهار اتصال داده رسمی بدون API key فعال‌اند: ECB SDMX برای نرخ‌های مرجع روزانه یورو، World Bank Indicators API v2 برای تورم سالانه CPI، BLS Public Data API v1 برای CPI/بیکاری/اشتغال ماهانه آمریکا و CFTC Public Reporting API برای موقعیت هفتگی معامله‌گران در قراردادهای ارز، طلا، نقره و نفت. این داده‌ها زمینه کلان و موقعیت‌گیری‌اند، نه نرخ اجرایی/لحظه‌ای یا سیگنال مستقل. منبع، تناوب و تاریخ مشاهده در گزارش درج می‌شود. BLS v1 بدون کلید است و محدودیت درخواست روزانه دارد؛ CFTC نیز صراحتاً درخواست بیش‌ازحد را منع می‌کند.
- بقیه منابع ۱۰۰تایی همچنان بر اساس دسترسی مجاز، API/RSS رسمی و شرایط استفاده به‌صورت مرحله‌ای متصل می‌شوند؛ منابعی که نیازمند API key، مجوز یا دسترسی دستی‌اند غیرفعال می‌مانند.
- معماری تحلیل و تست از پروژه‌های متن‌باز TA-Lib، pandas-ta-classic، vectorbt و backtesting.py الهام گرفته است؛ برای جلوگیری از زنجیره وابستگی و نصب سنگین، محاسبات پایه فعلاً با pandas/numpy پیاده‌سازی شده‌اند. این مخزن کد آن پروژه‌ها را کپی نمی‌کند.

## استخراج اولیه تحلیل‌ها

ماژول `src/experts/analysis_ingestion.py` از تیتر و خلاصه کوتاه feedهای مجاز، فقط فیلدهایی را استخراج می‌کند که صریحاً در متن دیده شوند: دارایی، جهت، تایم‌فریم، روش تحلیلی و سطوحی مثل target/entry/stop. موارد نامشخص حدس زده نمی‌شوند؛ جهت متناقض به‌صورت `conflicting` و نبود داده به‌صورت `not_stated` ثبت می‌شود. هر مورد با لینک، منبع، نویسنده (در صورت ارائه)، زمان انتشار/جمع‌آوری و وضعیت `unverified_source_claim` در گزارش نمایش داده می‌شود.

این مرحله هنوز موتور داوری معنایی یا اجماع نیست. متن کامل صفحات پولی/دارای محدودیت دریافت نمی‌شود؛ استخراج فعلی فقط از فراداده و خلاصه RSS انجام می‌شود. مرحله بعد باید تحلیل‌های مستقل را از نظر دارایی/افق زمانی/سطوح، وابستگی منابع، تضاد دیدگاه و سابقه قابل‌اندازه‌گیری تحلیلگر مقایسه کند.
